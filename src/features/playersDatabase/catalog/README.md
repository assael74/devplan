# קטלוגי PlayersDatabase

`clubs.catalog.js` הוא מקור האמת היחיד לרשימת המועדונים הבסיסית. הוא משמש
מקור קלט לאתחול `dbClubs` ומקור לבנייה מחדש של המידע הבסיסי לאחר מחיקה
מאושרת של המסד.

שכבות חיצוניות, לרבות מנגנון הסקאוטינג, קוראות את קטלוג המועדונים מהנתיב
הזה ואינן מחזיקות עותק נוסף.

הקטלוג אינו גיבוי מלא ל־Firestore. מידע ידני או מידע שנוצר בתהליכי ליגה,
סגל ונתונים סטטיסטיים נשמר או נבנה מחדש לפי החוזה של בעל המידע.
