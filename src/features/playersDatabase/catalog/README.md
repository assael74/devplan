# קטלוגי PlayersDatabase

`clubs.catalog.js` הוא מקור המידע הבסיסי לרשימת המועדונים ומשמש להתאמות,
בחירה ותצוגה בזרימות PlayersDatabase. אין ממנו פעולת אתחול או כתיבה גורפת
אל `dbClubs`.

שכבות חיצוניות, לרבות מנגנון הסקאוטינג, קוראות את קטלוג המועדונים מהנתיב
הזה ואינן מחזיקות עותק נוסף.

הקטלוג אינו גיבוי ל־Firestore. מידע ידני או מידע שנוצר בתהליכי ליגה, סגל
ונתונים סטטיסטיים נשמר או נבנה מחדש לפי החוזה של בעל המידע.
