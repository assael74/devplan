# מחיקת עונת ליגה V2

שני מסמכים עסקיים בלבד: League ו־LeaguesMaster. אין יבוא של כותבי Legacy.
זהות הליגה נשמרת תמיד; שאריות חוסמות ללא Cascade.

- כל הקריאות להכנה ולביקורת נעשות מהשרת.
- רשומות המאסטר והסיכום נבנים מכל הליגות הקנוניות.
- זמני העונות האחרות נשמרים; זמן מסמך הליגה נקבע לפני האישור ומוקרן למאסטר.
- Receipt תואם משמש ל־Retry עם קריאה, הכנה ואישור חדשים. אחרים אינם חוסמים.
- Audit מחייב expectedLifecycle: season_absent; זהות ליגה חסרה היא שגיאה.
- החיבור החדש במרכז הליגות בלבד. החיבור הישן בעמוד הליגה לא השתנה.
- סריקות מלאות נדרשות לזיהוי שאריות ומזהי עונה ישנים; יש לכך עלות קריאות.
- הפניית Root יתומה בעונה הנבדקת חוסמת ללא ניחוש שיוך לליגה.
- after-refresh Audit אינו מוכיח היסטורית שימור נתונים מלפני המחיקה.

נכתבו בדיקות לביקורת; הן לא הורצו. לא הורצו Build או כתיבות Firestore.
