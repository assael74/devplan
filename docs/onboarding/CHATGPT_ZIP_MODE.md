# ChatGPT ZIP Mode

## מעמד

זהו מסמך ההפעלה הפעיל לעבודה על DevPlan בצ׳אט רגיל באמצעות ZIP או snapshot.
הוא אינו נדרש ב־Codex Live Workspace.

## הוראה חד־פעמית ל־ChatGPT Project

את הטקסט הבא יש להוסיף פעם אחת ל־Project Instructions של פרויקט ChatGPT
שבו עובדים על DevPlan:

```text
כאשר מצורף ZIP או snapshot של DevPlan, עבוד במצב Chat ZIP/Snapshot.

לפני ניתוח או שינוי:
1. אתר וקרא את AGENTS.md בשורש הפרויקט שחולץ.
2. קרא את docs/README.md ובחר רק את מסמכי ההקשר הרלוונטיים למשימה.
3. קרא את .codex/skills/devplan-task-router/SKILL.md.
4. אם המשימה נוגעת ל-playersDatabase, קרא גם את
   .codex/skills/players-database/SKILL.md ואת
   src/features/playersDatabase/AGENTS.md.
5. אם המשימה היא UI או UX, קרא גם את
   .codex/skills/devplan-ui-ux/SKILL.md.

בחר את איש המקצוע המתאים לפי AGENTS.md לפני תחילת העבודה. אם אין התאמה
ברורה לסקיל, להגדרה או לתפקיד מקצועי, הצע את התפקיד והמוד הקרובים ביותר
ושאל אותי שאלה קצרה לפני מימוש.

התייחס ל-ZIP כתמונת מצב בלבד. אל תטען שהקוד החי עודכן. בסיום החזר רשימה
ברורה של קבצים ששונו, תוכן מלא לקבצים קטנים או patch ממוקד לקבצים קיימים,
והפרד בין עובדות שנבדקו לבין הנחות עקב קבצים חסרים.
```

## שימוש

- יש לוודא שה־ZIP כולל גם את התיקייה `.codex`.
- בכל שיחה מספיק לתאר את המשימה; אין צורך לציין ידנית איזה מסמך לקרוא.
- אם מעלים ZIP חלקי שאינו כולל `AGENTS.md`, `docs/README.md` או הסקיל הנדרש,
  ChatGPT צריך לדווח מה חסר ולשאול אם להמשיך לפי התפקיד הקרוב ביותר.
- כאשר מתקבל ZIP חדש, הוא מחליף את תמונת המצב הקודמת לצורך מסקנות על הקוד.
